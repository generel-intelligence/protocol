# Generel Intelligence protocol

This repository will own the versioned, implementation-independent contracts
used to exchange benchmark packages, run evidence, evaluation results, and
publication records across Generel Intelligence repositories.

## Status

Pre-alpha. M0 establishes governance only. No schema, fixture, SDK, or
compatibility promise exists until M1 publishes protocol `0.1.0`.

The protocol must remain independent of website, database, runner, evaluator,
and deployment implementations.
