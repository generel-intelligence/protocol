# Security policy

This repository is pre-alpha and has no supported release versions.

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/generel-intelligence/protocol/security/advisories/new).
Do not open a public issue. Reports are handled on a best-effort basis without
a response-time commitment.

See the canonical
[organization security policy](https://github.com/generel-intelligence/.github/blob/main/SECURITY.md).
